Reinforcement Learning with Robust Rubric Rewards
Extending rubric feedback into online learning: execute each criterion faithfully, preserve its signal, and prevent additional credit from compensating for essential failures.

Explore method details+
Execute with minimal exposure
Verifiable criteria use a text-only extractor followed by a deterministic verifier. Target arguments remain hidden from the extractor. Fuzzy criteria use a text-only judge with their grounding reference. Both paths exclude the source image.
Preserve essential failures
Decoupled normalization operates criterion by criterion across a response group. Hierarchical aggregation then gates the normalized reward: one essential score below 0.5, or at least two essential scores below 1, blocks content reward. A separate format mask handles response-level violations.
Toward a common model foundation
The open-source rubric-generator experiment initializes the generator from the same checkpoint as the policy and GenRM.
Rubric execution combines criterion-level verification with essential-aware reward aggregation.

rDPORubric-guided preference construction


Visual Preference Optimization with Rubric Rewards
Establishing reusable rubric supervision: build an offline instruction–rubric pool, score target-policy responses, and select preference pairs that reflect task-relevant quality differences.
Ya-Qi Yu, Fangyu Hong, Xiangyang Qu, Hao Wang, et al. · Huawei Technologies Co., Ltd.

Explore method details+
Build once, reuse across policies
Seed mining retains disagreement-rich instructions. Independent rubric drafts are aggregated into essential and additional criteria. This offline instruction–rubric pool can support response generation from different target policies.
Score repeatedly, select deliberately
Each candidate is scored three times, using a per-criterion median. Essential qualification controls chosen and rejected eligibility; weighted rewards enforce a margin. Up to four maximum-margin pairs are selected per instruction, with each unique response appearing at most twice.
Separate task quality from style recovery
The private scaling setting includes response-style constraints. rDPO recovers the prompting-induced degradation and exceeds the unconstrained base average; the full gain over prompting should not be interpreted as an unqualified reasoning gain.
Public and private settings serve different validation purposes. No empirical superiority over online GRPO is established by this study.
