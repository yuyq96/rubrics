# Rubric examples

12 illustrated cases in one JSONL file. Each record contains `id`, `question`, `rubric`, and image metadata. Each essential/additional rubric item contains `criterion`, `reference`, and `weight`.

Criterion descriptions and non-extractive references are in English. Literal image text and tool targets retain their original wording. Case IDs use the original response-ID prefixes.
